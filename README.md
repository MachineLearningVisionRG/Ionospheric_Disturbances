# Ionospheric Disturbances Dataset

All data, images and codes, supporting the findings of the work entitled **Machine Learning-Based Correlation of Earthquake Magnitude to Satellite Ionospheric Disturbances in the Hellenic Trench Region in Greece in the Month Before the Earthquakes by Chrysanthi Chariskou, Eleni Vrochidou and George A. Papakostas**, that is currently under review, will be openly available upon acceptance.
